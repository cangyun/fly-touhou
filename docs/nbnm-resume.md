# NBNM 暂停、续训与能力进度

一个共享的完整果蝇 SNN，16 个原作实例。每段 8192 个新决策、32 次 Adam；更新时原作停在原位置，更新后继续。单卡、整面、连段、开局六面连打均按 NBNM 判定，首次碰撞结束该次尝试；更新边界不结束游戏。

## 保存什么

`latest-training.pt` 保存参数、Adam、已完成更新位置、Torch/CUDA 随机状态、任务轮转与随机种子、每个仍在进行中的原作局的已执行输入，以及相应的 SNN 膜电位等内部状态。每段采样后、每 8 次 Adam、暂停时保存。`latest-rollout.pt` 使中途暂停的更新能够接着处理原采样段，不从第一个 minibatch 重做。

跨进程恢复时，原作 EXE 从同一种子重放该局已经执行的动作，重建感觉与教师历史，再装回对应 SNN 状态。重放不重新采样策略、不计作新训练数据、不产生重复的训练成绩。恢复过程中原作仍在私有桌面运行。长局恢复需要时间；它不是瞬间内存快照。

旧检查点没有原作连续记录，只能恢复学习进度并重新开局。不能从旧文件凭空找回已关闭的原作位置。意外崩溃会回到最后一个完整保存边界，尚未保存的部分采样需要重做。

## 操作

- 双击 `暂停NBNM专项训练.cmd`：当前采样段或当前 Adam 完成后保存并退出。以状态 `paused` 为准，别直接结束进程。
- 双击 `启动NBNM专项训练.cmd`：自动读取本次输出目录的 `latest-training.pt` 续训。
- 总预算已完成后再启动：按配置 `resume_extension_segments` 延长；未配置则延长 8 段。也可运行 `scripts/launch_nbnm.ps1 -AdditionalSegments 8` 指定增加量。
- 双击 `查看NBNM专项状态.cmd`：分别显示单卡/非符、整面、连段、六面连打的训练成绩与冻结成绩。

配置仍通过本机 `outputs/nbnm-local.json` 指定；依赖可使用既有 CUDA 环境。

## 定期能力记录

长训练每增加 65536 个新决策，或距上次冻结评测满 2 小时后，在下一个完整更新边界进行 20 个固定开发种子的全程 NBNM 评测。训练实例在原位置等待，评测结束后继续。报告位于 `development-<决策数>-full_story/report.json`，摘要写入 `capability-progress.json`，TensorBoard 的 `frozen/full_story/success_rate` 同步更新。

开发种子用于持续比较，不是独立最终测试。单卡或整面成功不能记为六面通关。训练中的成功也不等于冻结策略的成功率。

## 超时信息

原接口把整段关卡恢复的总耗时当成未响应；现在原作每次实际推进返回活动回执，只对持续没有推进的命令计空闲超时。真实错误和普通异常栈仍会上报，不会当作模型失败局或偷偷重置游戏继续计成绩。发现工作进程退出后立即报告，不再等待其他长恢复任务全部完成。

已移除每分钟异步抓取 Python 堆栈的诊断：本机 Python 3.11.9 的工作进程在该诊断打印栈时出现了访问违例，诊断本身不能成为训练依赖。原作活动回执和正常异常日志不受影响。历史 `worker-stalls.log` 保留作为故障证据。

## 按通过率分配局部训练量

`adaptive_course.enabled=true` 时，单卡／非符任务在局部 50% 配额内动态分配；整面与连段 25%、开局六面连打 25% 保持固定。成功轨迹复习继续保留，仍是一个共享网络。

- 使用每个局部任务最近 20 次已结束的学生训练尝试，原作确认的 NBNM 成功才算通过。中断、恢复重放、教师试玩和未结束局不计入通过率。
- 成功率用 `(成功数+2)/(尝试数+4)` 平滑。一次成功得到 60%，而非 100%；这只是分配采样的估计，不能当作冻结成绩。
- 难度分数为 `min(1, 0.25 + 0.75*(1-平滑通过率) + 0.5*退步量)`。退步量比较此前 20 次与最近 20 次的平滑通过率。
- 局部目标份额中 25% 均匀复习所有任务，75% 按难度分数分配。熟练任务减少训练但不会被移除；零通过任务也不能独占训练。
- 用实际已执行决策累计分配差额，选择欠缺训练量的任务；同时计入其他实例正在练的任务，避免同时扎堆。这样短局失败不会仅因“重开次数多”而看起来练了很多。
- 权重在每个采样段开始时更新；只有真实任务终止后才换题。各卡的实际份额会随局长波动，不承诺每个小段严格等于目标份额。
- `adaptive-course.json`、状态 API 和 TensorBoard `curriculum/<任务>/...` 展示近期成绩、目标份额、已采决策和退步量。调度统计、分配差额与随机状态跟随训练检查点保存。

完整局仍按 20 个开发种子的冻结评测报告结果。保留复习和全程训练能降低遗忘风险，但实际是否改善，需要看冻结结果。
