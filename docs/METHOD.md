# 模型与信息流

发布的 cycle087 与 cycle101 都属于 `full-connectome-compact129-spiking-story-PPO-v1` 系列；早期 GRU、连续网络和离线蒸馏模块虽保留在源代码中，但不是当前发布参数的模型。

```text
原作进程中的状态、对象、碰撞尺寸、运动及保护时段
        ↓ 工程化的候选运动几何预测与上下文
129 维观察 → 18 个候选，各 47 维
        ↓ 可训练的感觉编码（不是生物视网膜重建）
8053 个视觉投射端口
        ↓ 完整 138639 节点、15091983 条边的带符号脉冲连接组
1299 个下降神经元：滤波脉冲活动 + 模拟膜电位
        ├── 4/12/24 原作帧风险读出
        ├── 路线读出
        ├── Bomb 读出
        └── 三个价值头
        ↓ 保护期组合、动作合法性、family_mode 解码
执行一个动作并保留对应的全脑后继状态
```

脑连接的方向、节点集合和边集合不随训练重建；已有连接的幅度以及单元动力学参数可学习。输入/读出模块不属于解剖连接组。各候选使用相同网络、相同决策前脑状态，不是多个专家策略。

观察不是原始地图图像：129 维包含 18 个候选在多时距的几何危险线索、预测可信度、姿态/资源/关卡等信息。编码器把候选的几何线索与公共上下文合并为 47 维，经相反极性的神经元群和可训练残差输入视觉投射端口。工程化预测本身已提供任务知识，不能把全部成绩都归功于连接组拓扑。

循环状态包括模拟膜电位、突触状态、二值脉冲和滤波活动。使用阈值产生实际二值脉冲，训练使用代理梯度；一次动作的 16 次内部更新是工程离散步，不据此声称真实生物时间常数或神经放电记录。

风险和路线读出基于下降神经元活动；Bomb 读出使用候选下降活动的汇总。普通移动由神经预测和路线分数组合，保护时间、资源是否合法及不可控制时段会在外部解码器中处理。v6 第六面还调整神经风险各时距和路线分数的相对权重。这些都属于部署策略的一部分，必须连同权重一起复现。

训练由学生执行原作动作。教师为采集到的状态提供候选运动/风险及相关辅助目标，PPO 使用学生轨迹和三价值通道；教师档案还可用于辅助回放。教师辅助训练不等于推理时教师接管。本发布的冻结报告中教师动作数、优化步数均为零。

两个常见误读：

1. `release-data/selected_ports_1024_v783.json` 名称来自早期实验。当前构造器读取它是为了固定下降神经元顺序；视觉输入实际从注释表重新选择全部 8053 个匹配端口，并非只使用 1024 个。
2. 第六面解码设置不等于另一个第六面模型；参数和持续的脑状态仍由一个共享模型使用。

通关案例不证明生物动力学真实，不证明拓扑优于同规模人工图，也不证明稳定避弹。检验这些问题仍需要相应对照与独立评估。
