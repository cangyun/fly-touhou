# NBNM 训练准备

目标顺序：首先提高无 Bomb、无 Miss 的完成率，再缩短成功局的原作帧数。
这是新的训练任务；已通关的第 87 批参数和公开版本不被覆盖。

## 模型与输入

- 保留 138,639 个神经元、15,091,983 条有向连接、现有兴奋/抑制符号和 LIF 脉冲动力学。
- 8,053 个视觉投射端口输入，1,299 个下降神经元读出；每个候选动作仍执行 16 次内部更新。
- 原 129 维压缩状态保留；新增 18 个候选方向各 8 项路线信息，以及 8 项阶段/任务信息，总计 281 维。
- 路线信息包括较宽范围的 24 帧净空、条件线性 48/96 帧净空及有效性、18 个后续转向的出口比例、最佳余量和相反方向出口。
- 48/96 帧结果只基于当前已见对象。它不预测未来生成的子弹，不作为真实碰撞标签。已有 4/12/24 帧短程标签与实际原作碰撞记录继续用于校准。
- 感觉、动作、风险和脑内原有可训练参数均可更新。新增输入权重从零开始，原有脑和移动权重继承第 87 批；三个价值头的末层重新初始化，因为奖励语义改变了。
- 数值输入全部经过原有 VP 端口和脑网络。没有外置教师替学生执行动作，也没有另加绕过果蝇脑的路线动作筛选器。

`route` 与 `baseline` 共用同一结构、预算、教师和任务条件；`baseline` 仅将 144 维新路线输入置零。两组的教师仍看到相同的路线信息，避免把教师差异误当成输入效果。两组按顺序运行，默认先运行 route。

## 奖励和动作

三个价值通道：

| 通道 | 奖励 | 第一阶段 PPO 权重 | 提速阶段权重 |
|---|---|---:|---:|
| NBNM 完成 | 完成目标 +1；首次原作碰撞、Miss、Bomb 或 Game Over −1；其余 0 | 1 | 1 |
| 成功用时 | 仅成功终局得到 exp(−原作帧数 / 时间尺度) | 0 | 0.05 |
| 攻击进度 | 实测 Boss HP 进度，仅作辅助价值学习 | 0 | 0 |

使用 gamma=1、GAE lambda=0.995。失败得早不会少扣时间分；没有每帧扣时、下半场驻留收益、位置势函数、收资源收益或旧生存收入。

19 维输出保留以继承旧参数；Bomb 的概率严格为 0，环境也拒绝 Bomb 动作。第一触碰的原作 state4 就判失败，不等到 Miss 计数增长，更不能靠决死 Bomb 挽回。持续射击保持。

不强制下半场。无伤优先不等于蹲底，最快击破也不必然意味着待在下半场。站位通过真实完成率、全部方向的短程安全指导和后续出口学习，速度只在后续阶段参与策略目标。

移动监督采用学生当前场景的安全方向、未来净空、实际碰撞和 18 方向规则分布；决死专项监督权重为 0。首轮试训使用几何教师，不继承旧资源教师的上收、普通 Bomb、下半场指导及额外旧轨迹回放。后续难符卡试训改用 `resource-movement-v1`：继承完整规则教师的移动偏好，去除 Bomb 概率并重新归一化；它仍可能包含原教师的攻击和站位偏好，并不等于纯避弹标签。详情见文末的教师探针对照。

## 先验证单符卡，再扩大任务

默认试运行聚焦第三面 `BossCard1`，同时保留开局连打：

- 同一个共享果蝇模型，16 个原作实例：12 个进入专项、4 个从开局开始。
- 每段收集 8,192 次真实决策，严格分配 75% 专项、25% 连打；组内哪个实例就绪先处理哪个。
- 每段全部样本学习一遍，即 32 次 Adam 更新；没有 KL 早停、KL 学习率阈值或 8 次更新封顶。
- 初始预算 32,768 次决策、128 次 Adam。中间不插整局冻结评估；最后用未参与训练的原作种子作符卡冻结评估。
- 更新时原作暂停，之后从原位置继续。只有真实任务终局才重开，采样段结束不算终局。
- 用当前权重对前缀最后 64 个真实动作预热脑状态，已知动作只需计算一个候选。PPO 回放保留这份预热状态。
- 专项入口通过真实输入在原作中快速重放；并非进程内存快照或直接修改 ECL。前缀可能有 Bomb/Miss，**专项无伤成功不等于整局 NBNM**。
- 跨关加载可能让过关道具多移动少量帧、视觉随机数及 Bomb 库存有差异。NBNM 起点记录这些差异，不把已禁用的 Bomb 库存当成落点条件；最终仍核对人物、弹幕、道具、生命、火力、分数、脚本相对位置、玩法 RNG 和实际 Miss/Bomb/点道具事件。没有为了匹配落点而改写这些状态。进程地址只在比较时规范化。原有通关录像的严格重放规则保持原样。

起点库当前是小规模试运行集合，不能由它证明跨种子的稳定通关。有效后继续增加不同原作种子和第四至六面目标，仍更新同一个模型，并保留已通过内容的复习和完整开局验证。

速度阶段不会自动开启。当前工程门槛为同一任务至少 50 个不同原作种子的冻结评估、NBNM 完成率至少 90%，然后显式切换配置。0.05 的次要权重不是数学上严格的成功率约束：候选检查点仍必须先比较同组种子的成功数，成功数相同时才比成功局用时。专项用时尺度默认 3,600 帧，整局提速应改为约 36,000 帧。

## 提速与记录

- 使用全局就绪队列和任务组配额，避免等待每个实例都完成固定决策数。
- 不再额外重复执行旧 Bomb/资源教师回放；当前场景的监督与 PPO 共用一次脑网络反传。
- 采用已有的共享候选检查点反传、CUDA 稀疏乘法和融合边梯度。
- 推理可启用 CUDA Graph；每段采样结束释放图，更新后重新捕获，避免旧参数缓存。固定形状图减少 CPU 调度，但不减少 18×16 次脑计算，也不能据此承诺整轮训练提速数倍。[PyTorch 说明](https://docs.pytorch.org/docs/2.15/notes/cuda.html#cuda-graphs)
- 记录采样/学习用时、真实决策数、任务配额、原作碰撞、风险误判、NBNM 结果、成功用时及 PPO/价值/指导/风险损失。训练统计与冻结统计分开。
- 大文件默认放仓库 `outputs/`，可通过配置与缓存环境变量放到空间充足的磁盘；轮换保存最新训练状态和采样张量，另保留这四段各自的模型参数，JSON 日志保留。

续训配置用 `initial_checkpoint` 指定本轮起始参数，用 `reference_checkpoint` 保留第 87 批原始对照；配对脚本默认选择后者，`--initial` 可显式指定另一对照。默认只用开发种子，`--split test` 才使用独立测试种子。不同对照或不同数据划分应写入各自的新输出目录。


### 难符卡试训后的冻结结论与下一轮（2026-11-10）

上述追加试训已完成 16,384 次决策、64 次 Adam；连同首轮为 49,152 次决策、192 次更新。所有比较都使用最高概率动作，没有教师接管；两边入口观测一致。完整数字见 `results/nbnm-hard-card-frozen-comparison.json`。

| 任务与划分 | 第 87 批初始模型 | 追加试训后 | 配对变化 |
|---|---:|---:|---|
| 三面 BossCard1，Story 开发组 | 4/4 | 4/4 | 上一试训的 35537 退化恢复；同四局平均 2242→1490 帧 |
| 三面 BossCard2，原生练习开发组 | 3/4 | 3/4 | 1 个改善、1 个退化 |
| 四面 BossCard2，原生练习开发组 | 1/4 | 4/4 | 3 个改善、0 个退化；后者四局均击破 |
| 四面 BossCard2，20 个未用于训练/选模的测试种子 | 11/20 | 14/20 | 7 个改善、4 个退化；配对精确 p=0.5488 |

第四面测试的击破数为 10→13，另各有 1 局无伤撑到超时。开发组 4/4 没有在新种子上全部复现，**目前不能确认可靠、稳定的避弹提升，也没有因此启动完整六面训练**。测试种子覆盖的是固定小集合，不能代表所有原作种子。

三面 BossCard2 的新失败发生在开发种子 35846、第 292 帧；原始模型能通过。复现中，前 48 个状态有有效规则教师指导，学生只有 4 次选中教师的最高概率动作，多次继续靠近 Boss 而没有遵循下撤偏好；最后 25 个状态因路线余量不足或动态未知而没有指导。模态不一致本身不是错误证明，但与本次实际失败轨迹一起说明应检查早期路线学习。相同种子的完整规则教师 1152 帧无伤击破，不能把这个教师成绩记为学生成绩。

已应用两个后续修正：

- 原作 `0x42c8a0` 回调只写 ECL 查询变量。未来相关变量继续标为未知，只有真正读取它们并影响几何时才使预测失效；其他未知回调仍保持未知。同时补齐 ECL87 的方向角运算。隔离原作记录中 17 个可信位移/接触比较一致；没有据此宣布未解析的新生对象安全。
- 新增 `nbnm.rule_guidance_coefficient`，默认仍为 0.1。下一短试训设为 0.3，加强原有 18 方向规则分布监督；不增加风险排序项，不更改奖励、PPO、未知风险标签或脑连接结构。

预测器升级后的首次启动在 Story 起点比对阶段退出，未产生采样更新。差异仅为预测器版本、回调解析版本和模块地址元数据；原作位置、几何、标志及预测数值一致。NBNM 起点比较现排除这些实现元数据，仍比较所有原作和预测数值；相关 26 项测试通过，续跑已进入实际采样。

### 路线指导 v2 收尾：局部修复，四面退化（2026-11-10）

短试训已完成 8,192 次决策、32 次 Adam，16 个实例；全部采样行参与更新，拒绝更新数为 0。采样约 13.5 分钟、学习约 7.2 分钟。连同此前 NBNM 试训，累计 57,344 次决策、224 次更新。中途程序退出发生在训练已保存、冻结评测尚未完成时；恢复后没有重复训练，未完成的评测未计入成绩。

训练前采样的诊断也应与冻结成绩分开：

- 8,192 次决策中，只有 10 次尝试完整结束；三面难卡 4/4、四面难卡 1/4、Story 起点 1/2。这些是随机探索下的更新前轨迹，不是新模型的独立评测。

- 4 次实际碰撞前，选中方向的神经短程危险值均较高；其中 2 次在可信的 4 帧预测中已无安全方向，另 2 次几何预测未知。四次实际抽样动作均不是当时最高概率动作。证据支持继续调查更早的路线和未知威胁覆盖，不能只靠增加临撞前风险惩罚。

选定方法后，再检验未用于选模的新种子，并针对失败前尚可挽回的路线补实际规则教师纠错轨迹。当前没有依据仅凭这轮结果扩大脑网络、修改连接拓扑或宣称六面 NBNM。

### 连续任务与 NBNM 教师准备（2026-11-10）

本次完成工程准备，没有启动新一轮正式训练、更新真实学生检查点或启用自动晋级。下一轮继承路线指导 v2 的模型和 Adam；原有通关版、各轮检查点保留。完整果蝇节点、连接方向和连接拓扑不变，最终仍是一个共享脉冲策略。

参考 [CLEAR](https://proceedings.neurips.cc/paper/2019/hash/fa7cdfad1a5aaf8370ebeda47a1ff1c3-Abstract.html) 的经验复习思想，采用“新学生轨迹 PPO＋当前状态规则指导＋成功旧轨迹监督复习”。这不是原样实现 CLEAR，也没有把其离策略更新直接搬进 PPO。没有增加每张卡的部署专家、横向脑连接或 EWC 项。

| 环节 | 已实现的行为 |
|---|---|
| NBNM 教师 | `nbnm-route-v1` 从规划阶段禁用普通 Bomb 和决死；不再追求残机、Bomb 或 POC 上收，保留附近有用的 P 点和安全条件下的攻击偏好 |
| 路线 | 可信场景比较 4＋20 帧转向路线；必要时增加 4＋8＋12 帧、每个首动作保留两个中间落点的搜索。只指导首个 4 帧动作，下一决策重新规划 |
| 未知风险 | 仍区分可信/未知；找不到某条搜索路线不等于该动作必撞。4/12/24 帧风险标签保留原语义；48/96 帧只表示当前对象的条件性外推，不预测未来新生弹幕 |
| 连续任务 | `chain` 可以跨非符、符卡和关卡；只在指定终点、第一次实际接触或 Bomb 发生时结束，中间不重置游戏或脑状态、不额外发成功奖励 |
| 目标信息 | `critic-only-v1` 把最后四维任务范围信息从动作和风险通路屏蔽，仅输入三个价值头的人工接口。实际场景信息仍通过 VP、全脑和 DN 到动作/风险头 |
| 旧能力复习 | 成功轨迹中的实际移动做交叉熵监督。完整先前动作历史用当前权重重建脑状态；不把旧轨迹当 PPO 样本，也不把成功动作扩展为其他方向的安全标签 |
| 速度 | 成功时的速度回报已按任务接入 PPO，困难任务仍只优化 NBNM 成功。资格判定后可对合格任务单独启用 0.01 权重，不向其他混合任务传播；无逐帧时间罚分或下半场收入 |
| 更新 | 16 实例就绪优先；每 8192 个真实决策更新 32 次 Adam，正常更新边界不重开游戏。无 KL 早停，无阈值拒批 |
| 记录 | 按任务记录训练/冻结结果、实际决策配额、未知标签、路线查询数及教师耗时；保留 TensorBoard，并可启动只读本地状态 API |

路线是有限搜索，不是完整未来解算；无伤通关全六面仍须由学生实机验证。风险头、动作头、任务条件价值接口均为脑外人工读出，未据此声称它们属于果蝇原生解剖结构。

**第一轮可执行配置**：16 实例，32768 决策，4 个采样段，128 次 Adam。四面难卡 8 实例/50% 决策，三面已学难卡 4 实例/25%，三面 `BossCard1 → Boss2 → BossCard2` 连续链 4 实例/25%。复习系数 0.03，每 8 次 Adam 使用一个 16 步窗口；在线规则指导系数回到保守的 0.1，尚未宣称 0.3 就是上一轮下降的原因。

第一轮不做中途冻结；结束后分别测四面难卡、三面保留卡和连续链。单卡成功不能替代链通过，链通过不能替代全场 NBNM。下一阶段可把同一 `chain` 终点扩到三面末、四面末，随后增加从第一面真实开局开始的连续任务，最后使用 `full_story`。始终沿用同一网络参数，按自然场景继续行动，不在卡间切换模型。
