# Cycle 101：下半场默认习惯实验与退化

状态：训练已暂停；本轮冻结 20 局评估已完成，不会因发布/安装而恢复训练。

## 改了什么

在之前 v4 生存/资源/推进机制上加入下半场默认位置方案：

- 位置势函数参考 y=256，缩放 0.05，折扣 0.999；不是单纯“每帧在下面就持续加分”。
- 上半场条件惩罚为每 4 原作帧 0.0005。这一项不属于纯势函数塑形。
- 移动教师目标更偏向满足条件的下方方向；在记录数据中，偏好方向平均目标质量从 37.8% 增至 94.1%。
- 继续使用完整 SNN、三个价值头、既有神经风险和第六面保护期解码；没有把不同关卡拆成专家网络。

配置在 `configs/environment.json`，启动参数和算法记录分别在 `results/cycle101-training-launch.json`、`results/cycle101-algorithm.json`。启动记录中的历史输出路径是来源引用，并非全都包含在这个仓库中。

## 采样、优化与冻结结果

本轮新增 327,680 次采样决策、320 次 Adam 更新；选入 PPO 的行数为 81,920。累计统计为 2,179,072 次新学生动作、3,939 次 PPO 更新。采样决策、PPO 行数、优化次数与完整游戏局数不是同一单位。

第一批 16 个自然开局中，15 个 Game Over，剩下一个停在第五面；没有第一轮到达六面。第三、四面的 49 次 Miss 记录均处于 Bomb 库存为零时，38 次靠近侧边、29 次接近底边（两项有交集）。这些是观察，不能直接证明每次提前 Bomb 都无必要。

## 必须保留的问题

1. **目标变更未隔离**：势函数、条件惩罚和强移动目标重分配同时存在，不能把退化直接归因于一个奖励项。
2. **资源与解码**：训练的随机动作采样和冻结 `family_mode` 不同；训练中普通/未确认决死 Bomb 比例明显增加。风险意识、资源保留与最终动作选择需要联合分析。
3. **样本覆盖**：本轮进入 PPO 的第五面仅 1,087 行，第六面 0 行。继续机械增加早期采样不是已证实的解决方案。
4. **单轮语义缺陷**：Game Over 后自动重开使 59,283 次不希望的第二局决策进入采样（18.1%），其中 10,872 行进入 PPO（13.3%）。该缺陷没有在发布时悄悄修掉或隐藏；严格单轮需要实例退役和尾段处理。

训练轨迹使用滚动参数，不能用训练中的某次通关指认一个冻结参数。第 87 批固定种子的真实通关和本次第 101 批退化均应保留，后续改进应以新的冻结报告检验。
