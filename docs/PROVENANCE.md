# 来源与公共发布修改

`main` 的 `src/`、历史 `scripts/` 和基础依赖来自首次通关后保存的 `cycle087-v6-first-clear-20261102/source-snapshot.zip`；不是把第 101 批代码配上旧权重冒充旧版本。参数来自同一归档中的 `cycle087-parameters.pt`，保留原文件。

`experimental/latest` 在上述公共基线之上导入截至 2026-11-04 的工作源码，并使用第 101 批 `operator-stop-parameters.pt`（发布名 `cycle101-parameters.pt`）。这包括本轮实验结束后的停止/评估编排修订，结果报告仍来自原来实际运行的评估。

两条分支共享的发布整理：

1. 本机绝对路径转换为相对的历史输出占位路径；当前官方入口显式接收用户的游戏路径。
2. 缓存放置改为仓库 `outputs/cache` 或环境变量指定位置，不再隐式依赖发布者的 J: 盘。
3. 新增 `setup_release.py`、`run_release.py`、固定分支的配置/资源清单、说明和 CPU 测试。
4. 原先 ZIP 未收录 CUDA 编译源文件；从原工程补入对应的 `.cu`/`.cpp`，其中推理 SpMM 源码与首次通关使用的内核编译记录一致。补全这些文件与 Frida `.js` 的发行包资源声明。
5. 配置中的可选第六面演示前缀落盘开关关闭；它只生成录制文件，不改变模型输入、动作或原作 RNG。
6. 无渲染 DLL、模型参数以 Release 附件分发，连接组/注释从固定上游提交下载。源码中附 Rust 后端、许可证和原始端口顺序清单。

未在开源整理时改动网络算法、PPO/奖励、训练参数、神经权重或动作组合规则。格式及缓存路径修改不构成重新训练；首次通关不因重新打包就成为新的独立重复实验。

公共报告保留数值结果、开局种子、动作解码、评估范围和统计口径，去除原机器进程号和私人目录。部分报告中的历史 `outputs/...` 引用仅说明来源，不意味着 GitHub 仓库包含这些大型产物。

`native-windows-x86.zip` 中 DLL 来自原工程 2026-10-23 的 i686 构建，源代码及原始 MIT/Apache 许可证一同提供。没有原作 EXE、游戏资源、个人登录令牌、训练缓存或录制素材进入仓库。
